# Neural Network Practice

Практический проект по подготовке данных для последующего использования в нейронных сетях.

## Возможности

В проекте реализованы:

- интерфейс командной строки с использованием argparse;
- команда prepare для подготовки данных;
- команда doctor для проверки программного окружения;
- рекурсивный обход каталогов;
- поиск файлов по указанным расширениям;
- загрузка CSV-файлов в массивы NumPy;
- загрузка изображений с помощью Pillow;
- поддержка форматов .csv, .jpg, .jpeg, .png, .bmp, .gif, .webp;
- преобразование данных в тип float32;
- min-max нормализация CSV-данных;
- нормализация значений пикселей изображений в диапазон от 0 до 1;
- преобразование данных в одномерные массивы;
- приведение данных различного размера к единому формату;
- дополнение массивов нулевыми значениями (padding);
- объединение обработанных данных в единый массив NumPy;
- сохранение подготовленных данных в формате .npy;
- вывод статистики обработки;
- измерение времени выполнения;
- загрузка настроек из .env;
- использование переменных окружения через os.getenv();
- проверка версии Python и установленных библиотек;
- проверка доступности nvidia-smi с использованием subprocess.run().

Python 3.10+
NumPy
Pillow
python-dotenv


Запуск: 

1. Установить зависимости:
# Устанавливаем NumPy и Pandas.
python -m pip install -r requirements.txt

2. Запуск проекта с параметрами по умолчанию:
# Запускаем подготовку данных с настройками по умолчанию или из .env. 
python -m part2_data.app.main prepare

При выполнении программы:

- выполняется поиск файлов в каталоге с данными;
- файлы обрабатываются в зависимости от их расширения;
- данные преобразуются в массивы NumPy;
- выполняется нормализация;
- данные приводятся к единому размеру;
- результат сохраняется в файл .npy.

3. Запуск проекта с заданными параметрами --path / --ext / --output
# Указываем путь к данным, расширение файлов и путь для сохранения результата. 
python -m part2_data.app.main prepare --path part2_data/data --ext .csv --output part2_data/output/test_result.npy

4. Проверка программного окружения
# Запускаем диагностику программного окружения. 
python -m part2_data.app.main doctor

Команда проверяет:

- версию Python;
- наличие NumPy;
- наличие Pillow;
- наличие PyTorch;
- наличие TensorFlow;
- доступность nvidia-smi;
- текущую рабочую директорию;
- используемую операционную систему.

5. Настройки 

Программа поддерживает загрузку настроек из переменных окружения и файла .env.
Пример файла .env:

# Путь к каталогу с исходными данными.
DATA_PATH=part2_data/data
# Расширения файлов для обработки.
DATA_EXT=.csv
# Путь к итоговому файлу.
OUTPUT_PATH=part2_data/output/data.npy
# Уровень логирования.
LOG_LEVEL=INFO

6. Основные методы: 

fdata_processor.py

find_data_files() — рекурсивно ищет файлы с указанными расширениями.
load_csv() — загружает CSV-файл в массив NumPy.
load_image() — загружает и нормализует изображение.
load_file() — определяет тип файла и выбирает соответствующий способ загрузки.
normalize_csv() — выполняет min-max нормализацию CSV-данных.
normalize_data() — выполняет нормализацию с учётом типа файла.
prepare_data() — выполняет полный цикл подготовки данных.

doctor.py

check_python() — проверяет используемую версию Python.
check_library() — проверяет наличие Python-библиотеки.
check_cuda() — проверяет доступность nvidia-smi.
check_working_directory() — выводит текущую рабочую директорию.
check_environment() — выполняет полную проверку окружения.
